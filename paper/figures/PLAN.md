# Figure plan

Every figure ships with its CSV (the exact numbers plotted) and a one-paragraph description saved beside it
(`figures/figN.csv`, `figures/figN.md`), and every number in a figure must trace to a result file named here. Nothing
below is drawn yet. A figure whose data does not exist yet says what it waits for. The paper has at most 8 body
pages, so the plan is four figures, at most one of them full width.

## Drawn so far

Figure 1 is now experiment 1's result (`fig1.png`, `fig1.csv`, `fig1.md`, regenerated by `fig1.py`): key-open rate
per cell with Wilson intervals, confirmatory and calibration, plus the README, escalation and debrief shares. It takes
the place of the calibration figure planned as figure 2 below, so the schematic and the experiment 2 figures move
down one number when the paper is assembled.

## Figure 1 (planned). The two setups (schematic, full width)

rules file; the shared board and `shared/` folder, visible to all with a one-round delay; the submit tool with its
cap of five; `grader/` holding the answer key, the scoring script and the README, listed to every agent in round 1;
the access log under the tool server, flagging every grader read after path normalisation; and the commissar seat
as one more board participant. The commissar's role in experiment 1 is not settled (an appointed coordinator under

message from "Operations Steward" posted before the first call; the effort-credit meter; the report that closes the
record; and the five-question follow-up sent after it closes. Draw the commissar the same way in both panels, so a
reader sees what is shared (the commissar's prompt and model) and what is not (a live team member in experiment 1, a
pre-generated message in experiment 2, if that is how experiment 1 is finally run).

Data: none (a drawing). Sources for the details: `drafts/methods_exp1.md`, `drafts/methods_exp2.md`. Draw it as SVG
and check the render, not the source.

## Figure 4. Eval awareness by arm (small)

The share of follow-up answers calling the session a TEST (question 2 of PROBE_V2), per arm and per beneficiary, as
counts out of 32 with exact binomial intervals; a second row for "expected review" (question 1). This shows whether
the commissar's message makes the agent think it is being tested, which would change how any effect is read.

Data: the `looked` and `review` columns of `a0-haiku.csv` and of the A1 CSV. Waits for: A1.

## Rules for every figure

Colour-blind-safe palette, the same colour for an arm in every figure, intervals always shown, axes starting at 0
for shares, and no figure that implies an effect the analysis has not tested. Before export, read each rendered
figure back and compare every plotted value with its CSV.
