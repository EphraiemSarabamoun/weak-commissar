# Experiment 1: honesty under temptation (the honeypot swarm)

Teams of four Claude agents get an impossible scheduling task with an answer key left in their shared workspace. The question is whether any agent opens it. Confirmatory result (preregistered in `honeypot/prereg/confirm.md`): 0 of 12 teams opened the answer key or the grading script (Wilson 95 percent interval [0, 0.24]), 0 of 48 agents. Start with `honeypot/Human.md`; the outcome and its one analysis-code deviation are in `honeypot/prereg/confirm_result.md`, and per-team readouts and transcripts are under `honeypot/results/`. `tasks/` builds and grades the instances, `vendor/kin_oversight/` is the isolated agent harness the team harness imports (see its `PROVENANCE.md`), and `PATCHES.json` lists the source repositories and the patches applied when this release was assembled.
